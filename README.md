# 🚗 DataManager

## 📖 프로젝트 소개

DataManager는 DonkeyCar 자율주행 플랫폼을 보다 효율적으로 활용하기 위해 개발된 통합 관리 프로그램입니다.

---

## 👨‍💻 팀 구성

| 이름  | 담당 기능                                                                     |
| --- | ------------------------------------------------------------------------- |
| 문영진 | 데이터 관리 기능 개발 담당. 데이터 필터링(속도·각도), 프레임 범위 선택 및 삭제, 필터 목록 관리, 타임라인 시각화 기능 구현 |
| 배재용 | 모델 학습 기능 개발                                                               |
| 송찬휘 | 주행 분석 기능 개발                                                               |
| 김교범 | 차량 연결 및 데이터 동기화 기능 개발                                                     |

---

## ✨ 주요 특징

### ✔ 통합 환경 제공

* 데이터 관리
* AI 모델 학습
* 학습 결과 분석
* 차량 연결 및 동기화

### ✔ 직관적인 GUI

복잡한 터미널 명령어 대신 마우스 클릭만으로 대부분의 작업 수행 가능

### ✔ 시각적 데이터 분석

이미지, 그래프, 조향각, 속도 데이터를 실시간으로 확인 가능

### ✔ 데이터 정제 자동화

학습 품질을 떨어뜨리는 데이터를 빠르게 찾아 제거 가능

---

# 📂 1. 데이터 관리

## 개요

데이터 관리 메뉴는 DonkeyCar에서 수집된 주행 데이터(Tub)를 효율적으로 관리하고 정제하기 위한 기능을 제공합니다.

AI 모델의 성능은 학습 데이터의 품질에 크게 영향을 받기 때문에, 불필요한 데이터를 제거하고 원하는 데이터만 선별하는 과정이 중요합니다.

본 기능은 데이터 탐색, 필터링, 범위 선택, 삭제 및 복원 기능을 제공하여 학습 데이터 정제 과정을 보다 쉽고 효율적으로 수행할 수 있도록 설계되었습니다.

---

## 주요 기능

### 📁 데이터 불러오기

학습에 사용할 Tub 데이터를 불러오는 기능입니다.

- Tub 폴더 선택
- 이미지 자동 로딩
- JSON 데이터 로딩
- 프레임 정보 표시
- 데이터 개수 확인

주행 데이터를 GUI 환경에서 손쉽게 확인할 수 있습니다.

---

### 🎞 프레임 탐색

주행 영상을 프레임 단위로 탐색할 수 있습니다.

- 첫 프레임 이동
- 마지막 프레임 이동
- 이전 프레임 이동
- 다음 프레임 이동
- 자동 재생

원하는 구간을 빠르게 확인할 수 있습니다.

---

### 📊 실시간 주행 데이터 확인

현재 프레임의 주행 정보를 실시간으로 확인할 수 있습니다.

표시 정보

- 조향각(Angle)
- 속도(Throttle)
- 프레임 번호

주행 데이터 상태를 직관적으로 확인할 수 있습니다.

---

### 🎯 프레임 범위 선택 기능

특정 구간을 선택하여 관리할 수 있습니다.

지원 기능

- 좌측 설정
- 우측 설정
- 범위 지정
- 범위 목록 저장

사용자가 원하는 구간을 빠르게 선택할 수 있습니다.

---

### 📋 범위 목록 관리

선택한 범위를 목록 형태로 관리할 수 있습니다.

- 범위 추가
- 범위 확인
- 범위 선택
- 범위 삭제

여러 개의 범위를 동시에 관리할 수 있습니다.

---

### 🗑 데이터 삭제 기능

불필요한 데이터를 제거하여 학습 데이터 품질을 향상시킬 수 있습니다.

지원 기능

- 단일 프레임 삭제
- 범위 삭제
- 다중 범위 삭제
- 전체 범위 삭제

효율적인 데이터 정제가 가능합니다.

---

### ♻ 삭제 데이터 복원

삭제 예정 데이터에 대해 복원 기능을 제공합니다.

- 삭제 취소
- 전체 복원
- 상태 초기화

실수로 삭제한 데이터를 복구할 수 있습니다.

---

### ⚡ 속도 필터 기능

특정 속도 범위의 데이터만 선택할 수 있습니다.

지원 기능

- 최소 속도 설정
- 최대 속도 설정
- 슬라이더 조절
- 필터 적용
- 필터 저장

예시

- 0.0 ~ 0.3
- 0.3 ~ 0.7
- 0.7 ~ 1.0

원하는 속도 영역만 선별할 수 있습니다.

---

### 🔄 각도 필터 기능

특정 조향각 범위의 데이터만 선택할 수 있습니다.

지원 기능

- 최소 각도 설정
- 최대 각도 설정
- 슬라이더 조절
- 필터 적용
- 필터 저장

지원 범위

- -1.0 ~ 1.0

직진, 좌회전, 우회전 구간을 쉽게 분류할 수 있습니다.

---

### 📑 필터 목록 관리

등록된 필터를 목록으로 관리할 수 있습니다.

지원 기능

- 속도 필터 목록
- 각도 필터 목록
- 필터 선택
- 개별 필터 삭제
- 전체 필터 초기화

반복적인 필터 설정 작업을 줄일 수 있습니다.

---

### 📈 타임라인 시각화

타임라인을 이용하여 데이터 상태를 한눈에 확인할 수 있습니다.

표시 항목

- 현재 프레임
- 선택 범위
- 삭제 예정 데이터
- 필터 적용 결과

색상을 활용하여 데이터 상태를 직관적으로 확인할 수 있습니다.

---

### 🎨 사용자 편의 기능

데이터 관리 작업의 효율성을 높이기 위한 다양한 기능을 제공합니다.

- 범위 목록 UI
- 필터 목록 UI
- 삭제 개수 표시
- 상태 정보 표시
- 실시간 화면 갱신

대량의 주행 데이터를 보다 편리하게 관리할 수 있습니다.

# 🧠 2. 모델 학습

## 개요

모델 학습 메뉴는 DonkeyCar 주행 데이터를 기반으로 AI 자율주행 모델을 생성하는 기능을 제공합니다.

사용자는 학습에 필요한 다양한 설정을 직접 조정할 수 있으며, 학습 진행 상황을 실시간으로 확인하고 생성된 모델을 효율적으로 관리할 수 있습니다.

---

## 주요 기능

### ⚙ 모델 설정

학습에 사용할 모델의 기본 정보를 설정할 수 있습니다.

- 모델 유형 선택
- 모델 이름 설정
- 학습 메모 작성
- 전이학습 모델 선택

사용 목적에 맞는 학습 환경을 구성할 수 있습니다.

---

### 📚 학습 파라미터 설정

모델 성능에 영향을 주는 주요 학습 옵션을 설정할 수 있습니다.

- Epoch 설정
- Batch Size 설정
- Train/Test 비율 설정
- 학습 옵션 조정

다양한 환경에 맞춰 학습 성능을 최적화할 수 있습니다.

---

### 🛠 고급 설정

Config 파일의 세부 항목을 직접 수정할 수 있습니다.

- KEY-VALUE 방식 설정
- 학습 옵션 수정
- 사용자 정의 설정 추가

고급 사용자를 위한 세밀한 튜닝 기능을 제공합니다.

---

### 💾 프리셋 관리

자주 사용하는 학습 설정을 저장하고 재사용할 수 있습니다.

- 프리셋 저장
- 프리셋 복사
- 프리셋 불러오기
- 프리셋 삭제

반복적인 설정 작업을 줄여 학습 준비 시간을 단축할 수 있습니다.

---

### ▶ 학습 실행

설정된 학습 환경을 바탕으로 모델 학습을 수행합니다.

- 학습 시작
- 학습 중단
- 진행 상태 확인

학습 과정을 GUI 환경에서 편리하게 관리할 수 있습니다.

---

### 📜 학습 로그 확인

학습 중 발생하는 정보를 실시간으로 출력합니다.

- 학습 진행률 확인
- 오류 메시지 확인
- 학습 상태 모니터링

문제 발생 시 원인을 빠르게 파악할 수 있습니다.

---

### 🤖 모델 관리

학습 완료 후 생성된 모델을 목록 형태로 관리할 수 있습니다.

표시 정보

- 모델 이름
- 모델 유형
- 학습 시간
- 사용 데이터 경로
- 전이 모델 정보
- 메모

생성된 모델을 체계적으로 관리할 수 있습니다.

---

### 📊 학습 결과 분석

학습 결과를 그래프로 시각화하여 성능을 분석할 수 있습니다.

- Loss 그래프 확인
- 학습 추이 분석
- 모델 성능 비교

학습 결과를 직관적으로 확인하고 개선 방향을 파악할 수 있습니다.

---

# 📈 3. 주행 분석

## 개요

주행 분석 메뉴는 사용자가 직접 주행한 데이터와 AI 모델이 예측한 주행 데이터를 비교하여 학습 성능을 분석하는 기능을 제공합니다.

단순히 모델을 학습시키는 것에서 끝나는 것이 아니라, 실제로 어느 구간에서 오차가 발생했는지 시각적으로 확인할 수 있어 모델 성능 개선에 도움을 줍니다.

---

### 📂 데이터 불러오기

분석에 사용할 Tub 데이터를 불러오는 기능입니다.

- 사용자 주행 데이터 추가
- AI 주행 데이터 추가
- 데이터 목록 관리

여러 개의 주행 데이터를 등록하여 비교 분석할 수 있습니다.

---

### 📊 오차 분석

사용자 데이터와 AI 예측값의 차이를 계산하여 표시합니다.

분석 항목

- 종합 오차
- 조향각(Angle) 오차
- 속도(Throttle) 오차

오차 값을 통해 모델의 정확도를 정량적으로 확인할 수 있습니다.

---

### 🎞 프레임 단위 분석

현재 프레임의 사용자 입력값과 AI 예측값을 비교하여 확인할 수 있습니다.

확인 가능 정보

- 사용자 조향값
- AI 조향값
- 사용자 속도값
- AI 속도값
- 오차 정보

특정 프레임에서 발생한 문제를 빠르게 확인할 수 있습니다.

---

### 🎨 이미지 시각화 기능

주행 영상을 보다 편하게 분석할 수 있도록 이미지 효과를 제공합니다.

지원 기능

- 밝기 조절
- 흐림 효과 적용
- 실시간 미리보기

어두운 영상이나 노이즈가 많은 영상을 보다 쉽게 확인할 수 있습니다.

---

### ▶ 재생 및 프레임 이동

주행 영상을 탐색하며 데이터를 분석할 수 있습니다.

지원 기능

- 이전 프레임 이동
- 다음 프레임 이동
- 자동 재생
- 특정 구간 확인

영상과 데이터를 함께 보면서 주행 흐름을 분석할 수 있습니다.

---

### 📈 그래프 생성

주행 데이터를 그래프로 시각화하여 변화 추이를 확인할 수 있습니다.

지원 그래프

- 종합 오차 그래프
- 조향각 그래프
- 속도 그래프

시간에 따른 데이터 변화를 직관적으로 확인할 수 있습니다.

---

### 📉 오차 시각화

AI와 사용자의 차이를 그래프로 표시합니다.

표시 정보

- 기준선(0)
- 오차값
- 사용자 입력값
- AI 예측값

모델이 어느 구간에서 잘못 예측했는지 쉽게 파악할 수 있습니다.

---

### 🎯 주행 품질 평가

그래프와 오차 데이터를 기반으로 모델의 주행 성능을 평가할 수 있습니다.

기대 효과

- 학습 결과 검증
- 문제 구간 탐색
- 데이터 품질 확인
- 모델 개선 방향 도출

AI 모델의 성능을 보다 객관적으로 분석할 수 있습니다.

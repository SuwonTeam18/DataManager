# 🚗 DataManager

## 📖 프로젝트 소개

DataManager는 DonkeyCar 자율주행 플랫폼의 데이터 정제, 모델 학습, 성능 분석 과정을 하나의 GUI 환경에서 수행할 수 있도록 개발된 통합 관리 프로그램입니다.

사용자는 복잡한 명령어 입력 없이 데이터 품질 개선부터 AI 모델 학습, 주행 성능 분석까지 전 과정을 직관적으로 수행할 수 있습니다.

# 📂 1. 데이터 관리

## 개요

데이터 관리 메뉴는 DonkeyCar에서 수집된 주행 데이터(Tub)를 효율적으로 관리하고 정제하기 위한 기능을 제공합니다.

AI 모델의 성능은 학습 데이터의 품질에 크게 영향을 받기 때문에, 불필요한 데이터를 제거하고 원하는 데이터만 선별하는 과정이 중요합니다.

본 기능은 데이터 탐색, 필터링, 범위 선택, 삭제 및 복원 기능을 제공하여 학습 데이터 정제 과정을 보다 쉽고 효율적으로 수행할 수 있도록 설계되었습니다.

# 🧠 2. 모델 학습

## 개요

모델 학습 메뉴는 DonkeyCar 주행 데이터를 기반으로 AI 자율주행 모델을 생성하는 기능을 제공합니다.

사용자는 학습에 필요한 다양한 설정을 직접 조정할 수 있으며, 학습 진행 상황을 실시간으로 확인하고 생성된 모델을 효율적으로 관리할 수 있습니다.

---

## 주요 기능

### ⚙ 모델 설정

<img width="1198" height="468" alt="모델 설정" src="https://github.com/user-attachments/assets/9be59397-b4f9-49d5-addb-573e1758f486" />


학습에 사용할 모델의 기본 정보를 설정할 수 있습니다.

- **모델 유형 선택** — linear, categorical, rnn 등 다양한 유형 중 목적에 맞는 모델을 선택할 수 있습니다. 각 유형 선택 시 하단에 해당 모델의 특징과 필요 데이터에 대한 설명이 표시됩니다.
- **모델 이름 설정** — 학습 후 저장될 모델 파일명을 지정합니다. 입력하지 않으면 `mypilot`으로 자동 설정됩니다.
- **학습 메모 작성** — 해당 학습에 대한 메모를 남길 수 있으며, 나중에 모델 목록에서 확인할 수 있습니다.

사용 목적에 맞는 학습 환경을 구성할 수 있습니다.

---

### 📚 학습 파라미터 설정

<img width="1218" height="808" alt="학습 파라미터 설정" src="https://github.com/user-attachments/assets/d21482b9-4ed4-4fba-b3b3-791b9dc03d79" />


모델 성능에 영향을 주는 주요 학습 옵션을 설정할 수 있습니다.

- **Epoch 설정** — 전체 데이터를 몇 번 반복해서 학습할지 지정합니다. 슬라이더와 숫자 입력 두 가지 방식으로 조정할 수 있습니다.
- **Batch Size 설정** — 한 번에 처리할 데이터 묶음의 크기를 설정합니다. 클수록 학습이 빠르지만 메모리를 많이 사용합니다.

다양한 환경에 맞춰 학습 성능을 최적화할 수 있습니다.

---

### 🛠 고급 설정

<img width="1214" height="642" alt="고급 설정, 프리셋 관리" src="https://github.com/user-attachments/assets/a1d354ce-9bb9-4b7c-b96f-631832ebf2e0" />


`myconfig.py`의 세부 항목을 직접 파일을 열어 수정하지 않고 KEY-VALUE 방식으로 입력하면 학습 시 자동으로 반영됩니다. 학습이 끝나면 다음 학습 시 기본 설정으로 다시 초기화되므로 이전 설정이 누적되지 않습니다.

- **KEY-VALUE 방식 설정** — 설정 항목명(KEY)과 값(VALUE)을 입력하면 됩니다.
- **항목 추가/삭제** — 필요한 설정을 자유롭게 추가하거나 제거할 수 있습니다.

자주 쓰는 고급 설정 예시:

| KEY | VALUE | 설명 |
|-----|-------|------|
| EARLY_STOP_PATIENCE | 2 | 조기 종료 기준 에포크 수 |
| MIN_DELTA | 0.0005 | 개선으로 인정하는 최소 변화량 |

**기본 설정 저장** 버튼을 누르면 현재 `myconfig.py` 상태를 기준으로 저장합니다. 처음 사용 전 한 번 눌러두는 것을 권장합니다.

---

### 💾 프리셋 관리

자주 사용하는 학습 설정(에포크, 배치 크기, 고급 설정 포함)을 프리셋으로 저장하고 재사용할 수 있습니다. 프리셋은 프로그램을 껐다 켜도 유지됩니다.

- **프리셋 저장** — 현재 설정 상태를 프리셋으로 저장합니다.
- **프리셋 복사** — 기존 프리셋을 복제해서 일부만 수정해서 사용할 수 있습니다.
- **프리셋 불러오기** — 목록에서 선택하면 해당 프리셋의 설정이 자동으로 적용됩니다.
- **프리셋 삭제** — 더 이상 필요 없는 프리셋을 제거합니다.

반복적인 설정 작업을 줄여 학습 준비 시간을 단축할 수 있습니다.

### ▶ 학습 실행

<img width="671" height="352" alt="학습 실행,학습 로그 확인" src="https://github.com/user-attachments/assets/9ac3f75f-1e63-471a-9cb3-7f64318cf4c8" />


설정된 학습 환경을 바탕으로 모델 학습을 수행합니다. 데이터 관리 탭에서 데이터 폴더를 먼저 열어야 경로가 자동으로 연동됩니다. 데이터 관리 탭에서 삭제하거나 필터한 데이터는 학습 시 자동으로 제외되며, 원본 데이터는 그대로 보존됩니다.

- **학습 시작** — 설정된 조건으로 학습을 시작합니다.
- **학습 중단** — 진행 중인 학습을 언제든지 중단할 수 있습니다.
- **진행 상태 확인** — 현재 에포크와 손실값이 실시간으로 표시됩니다.

학습 과정을 GUI 환경에서 편리하게 관리할 수 있습니다.

---

### 📜 학습 로그 확인

학습 중 발생하는 모든 정보를 실시간으로 출력합니다.

- **에포크 진행률** — 현재 몇 번째 에포크가 진행 중인지 확인할 수 있습니다.
- **손실값 모니터링** — 훈련 손실(loss)과 검증 손실(val_loss)이 에포크마다 갱신됩니다. 초록색 **(최저)** 표시는 현재 에포크가 가장 좋은 상태임을 의미하고, 빨간색으로 표시된 차이값은 최저 대비 얼마나 나빠졌는지를 나타냅니다.
- **조기 종료 감지** — 학습 도중 val_loss가 일정 에포크 수만큼 연속으로 개선되지 않으면 학습이 자동으로 중단되고 **⚠ 조기 종료** 문구와 함께 중단된 에포크가 표시됩니다.
- **오류 메시지 확인** — 문제 발생 시 로그에서 원인을 빠르게 파악할 수 있습니다.

### 🤖 모델 관리

### 📊 학습 결과 분석

학습 결과를 그래프로 시각화하여 성능을 분석할 수 있습니다. 학습이 완료되면 손실 히스토리가 자동으로 저장되며, 모델 목록에서 모델을 선택하고 **그래프 보기** 버튼을 누르면 언제든지 다시 확인할 수 있습니다.

- **전체 오차 (loss / val_loss)** — 전체적인 학습 진행 추이를 확인합니다.
- **핸들 방향 오차 (n_outputs0)** — 핸들 각도 예측의 정확도를 확인합니다.
- **속도 조절 오차 (n_outputs1)** — 속도 예측의 정확도를 확인합니다.

두 선(훈련/검증)의 차이가 크면 과적합 상태를 의심할 수 있습니다. 학습 결과를 직관적으로 확인하고 개선 방향을 파악할 수 있습니다.

---

## 주의사항

- 데이터 관리 탭에서 데이터 폴더를 먼저 열어야 경로가 자동 연동됩니다
- 프로그램을 강제 종료하면 내부적으로 수정된 설정 파일이 복구되지 않을 수 있습니다

# 📈 3. 주행 분석

## 개요

주행 분석 메뉴는 사용자가 직접 주행한 데이터와 AI 모델이 예측한 주행 데이터를 비교하여 학습 성능을 분석하는 기능을 제공합니다.

단순히 모델을 학습시키는 것에서 끝나는 것이 아니라, 실제로 어느 구간에서 오차가 발생했는지 시각적으로 확인할 수 있어 모델 성능 개선에 도움을 줍니다.

---

## 주요 기능

### 🤖 모델 불러오기

<img width="1214" height="1000" alt="모델 불러오기" src="https://github.com/user-attachments/assets/680f3a5d-ed45-4e9c-850e-634c1f687f39" />

주행 분석 탭에서 여러 AI 모델을 불러와 동시에 비교할 수 있습니다.

- 파일럿 추가 및 제거 기능 제공
- 최대 4개의 모델 동시 등록 가능
- 1열 ~ 4열 위치 자유 지정
- 여러 AI 모델 성능 비교 분석 지원

### 🤖 파일럿 슬롯

분석에 사용할 AI 모델을 슬롯 단위로 선택하고 관리합니다. 슬롯은 최대 4개까지 추가할 수 있으며, 각 슬롯마다 서로 다른 모델을 선택해 동시에 비교할 수 있습니다. 모델을 선택하면 현재 프레임에 대한 AI 예측값이 즉시 화면에 표시됩니다.

각 슬롯 아래에는 AI가 예측한 각도와 속도, 사람 데이터와의 오차, 전체 데이터에 대한 평균 오차율이 표시됩니다. 평균 오차율은 전체 이미지를 백그라운드에서 자동으로 계산하며, 계산이 완료되면 갱신됩니다.

---

### 🖼 이미지 오버레이 시각화

<img width="606" height="369" alt="오차 분석,프레임 단위 분석, 재생 및 프레임 이동" src="https://github.com/user-attachments/assets/8d766184-6ffb-43cb-8eee-67c6aec8bf34" />

현재 프레임 이미지 위에 사람의 조작값과 AI 예측값을 화살표로 겹쳐서 보여줍니다.

- **주황색 화살표** — 사람이 실제로 조작한 핸들 각도와 속도
- **하늘색 화살표** — AI가 예측한 핸들 각도와 속도

화살표의 기울기는 핸들 각도를, 길이는 속도를 나타냅니다. 두 화살표가 겹칠수록 AI가 사람과 유사하게 판단하고 있다는 의미입니다.

---

### 📊 오차율 순위

여러 모델을 동시에 비교하여 오차율 기준으로 순위를 표시합니다. 종합, 각도, 속도 기준 중 원하는 항목을 선택해서 확인할 수 있으며, 1~3위를 메달 형태로 표시합니다.

모델을 선택하면 전체 이미지에 대한 예측 계산이 자동으로 시작되고, 완료되면 순위가 자동으로 갱신됩니다. 모델을 바꾸면 해당 슬롯의 계산만 취소하고 새 모델로 다시 시작하므로 다른 슬롯에는 영향을 주지 않습니다.

---

### 🎞 프레임 단위 탐색

슬라이더나 버튼으로 프레임을 이동하며 각 시점의 데이터를 확인할 수 있습니다. 기록 번호를 직접 입력해서 특정 프레임으로 바로 이동하는 것도 가능합니다.

- **이전/다음 프레임** — 한 장씩 이동
- **100장 이전/이후** — 빠른 이동
- **자동 재생** — 배속 설정 가능 (0.25x ~ 2.00x)
- **데이터 관리 탭과 동기화** — 어느 탭에서 이동해도 양쪽이 함께 이동

### 🎨 이미지 필터

<img width="1206" height="736" alt="이미지 시각화 기능" src="https://github.com/user-attachments/assets/8d717241-3715-4b19-bc43-17bdec6d739a" />


주행 영상을 보다 편하게 분석할 수 있도록 이미지 효과를 조절할 수 있습니다.

- **밝기 조절** — 어두운 영상을 밝게 보정할 수 있습니다
- **흐림 효과** — 노이즈가 많은 영상을 부드럽게 처리할 수 있습니다
- **필터 적용** — 현재 필터값으로 AI 예측도 다시 수행합니다. 학습 시 사용한 전처리 조건과 동일하게 맞추면 더 정확한 비교가 가능합니다
- **필터 삭제** — 필터를 초기화합니다

### 📈 그래프 생성 (Tub Plot)

<img width="853" height="723" alt="그래프 생성" src="https://github.com/user-attachments/assets/f53892df-19c6-4b19-a92b-949cf7881ff8" />


Tub Plot 버튼을 누르면 모델과 옵션을 선택하는 팝업이 뜨고, 전체 이미지에 대한 AI 예측 그래프를 생성합니다. 그래프는 50장마다 점진적으로 채워지며 백그라운드에서 계산됩니다.

그래프는 X축이 프레임 번호, Y축이 값으로 아래 세 가지 모드를 제공합니다.

- **각도 모드** — 사람의 핸들값과 AI 예측값을 겹쳐서 비교합니다
- **속도 모드** — 사람의 속도값과 AI 예측값을 겹쳐서 비교합니다
- **오차율 모드** — 프레임마다 AI와 사람의 차이를 선으로 표시합니다. 종합/각도/속도 기준으로 전환할 수 있습니다

그래프는 마우스로 확대·축소 및 드래그할 수 있습니다.
- **Shift + 스크롤** — 가로 확대/축소
- **Ctrl + 스크롤** — 세로 확대/축소
- **드래그** — 그래프 이동

### 📉 오차 시각화

<img width="1220" height="306" alt="오차 시각화 그래프," src="https://github.com/user-attachments/assets/0b14ee3d-f5b8-4eab-b40d-349fb5d1152d" />


오차율 모드에서 그래프의 두 선이 의미하는 바는 다음과 같습니다.

- **기준선(0)** — 오차가 없는 상태
- **오차값 선** — 프레임마다 AI와 사람의 차이

오차값이 0에 가까울수록 AI가 사람과 유사하게 판단한 것입니다. 특정 구간에서 오차가 크면 그 구간의 주행 패턴을 AI가 잘 학습하지 못했다는 의미로, 해당 구간의 데이터를 보강해서 재학습하는 방향으로 활용할 수 있습니다.

### 🎯 주행 품질 평가

<img width="1194" height="328" alt="주행 품질 평가" src="https://github.com/user-attachments/assets/b1478b40-7b79-4d26-acae-dd04968bc9d7" />


그래프와 오차 데이터를 종합해서 모델의 주행 성능을 평가할 수 있습니다.

-  각 모델의 전체 이미지에 대한 예측값과 사람 조작값의 차이를 평균 절대 오차(MAE) 방식으로 계산해 평균 오차율을 산출합니다. 
-  각도 오차율, 속도 오차율, 두 값의 평균인 종합 오차율로 나뉘며, 계산이 완료된 모델들은 오차율 낮은 순으로 자동 정렬되어 순위로 표시됩니다.
-  이를 통해 같은 데이터로 학습한 여러 모델 중 어떤 모델이 사람의 주행 패턴을 가장 잘 재현하는지 정량적으로 비교할 수 있습니다.

#  📌 프로젝트 목표



기존 DonkeyCar 환경에서는 주행 데이터 관리, 모델 학습, 학습 결과 분석 과정을 각각 다른 도구와 명령어를 사용하여 수행해야 했다. 이러한 방식은 초보자가 사용하기 어렵고, 데이터 정제와 모델 성능 분석 과정에서 많은 시간이 소요된다는 문제가 있었다.

DataManager는 이러한 문제를 해결하기 위해 데이터 수집 이후의 전 과정을 하나의 GUI 환경으로 통합하는 것을 목표로 개발되었다.

단순히 데이터를 확인하는 수준을 넘어, 사용자가 학습 데이터의 품질을 직접 개선할 수 있도록 데이터 정제 기능을 강화하였다. 범위 선택 삭제, 속도·조향각 필터링, 필터 목록 관리, 타임라인 시각화 기능을 통해 대량의 주행 데이터에서 불필요한 데이터를 빠르게 선별하고 제거할 수 있도록 설계하였다.

또한 모델 학습 기능과 주행 분석 기능을 연계하여 데이터 정제 → 모델 학습 → 성능 분석 과정을 하나의 프로그램 안에서 수행할 수 있도록 구현하였다.



# 🎯 기대 효과
데이터 품질 향상

사용자가 불필요한 주행 데이터를 직접 제거하고 원하는 조건의 데이터만 선별할 수 있어 학습 데이터의 품질을 향상시킬 수 있다.

모델 성능 개선

정제된 데이터를 기반으로 학습을 수행함으로써 AI 모델의 예측 정확도와 주행 성능 향상을 기대할 수 있다.

작업 시간 단축

기존에 여러 프로그램과 명령어를 사용하던 작업을 하나의 GUI 환경에서 처리하여 작업 시간을 단축할 수 있다.

직관적인 분석 환경 제공

사용자 주행 데이터와 AI 결과를 그래프와 이미지로 비교 분석하여 문제 구간을 쉽게 파악할 수 있다.

프로젝트의 차별성

본 프로젝트는 단순히 데이터를 확인하거나 학습만 수행하는 도구가 아니라, 데이터 정제 → 학습 → 분석 과정을 하나의 흐름으로 연결하여 자율주행 모델 개발 전 과정을 지원하는 통합 관리 시스템이라는 점에서 차별성을 가진다.

🚗 DataManager

📖 프로젝트 소개

Datamanager는 DonkeyCar 자율주행 플랫폼을 보다 효율적으로 활용하기 위해 개발된 통합 관리 프로그램입니다.

기존 DonkeyCar 환경에서는 주행 데이터 관리, 모델 학습, 학습 결과 분석, 차량과의 데이터 동기화 등을 각각 개별 명령어와 파일 편집을 통해 수행해야 했습니다.

본 프로젝트는 이러한 과정을 하나의 GUI 환경으로 통합하여 누구나 직관적으로 사용할 수 있도록 설계되었습니다.

사용자는 복잡한 명령어 입력 없이 주행 데이터를 정제하고, AI 모델을 학습시키며, 학습 결과를 시각적으로 분석하고, 차량과 데이터를 동기화할 수 있습니다.

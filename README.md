# 🚗 DataManager

## 📖 프로젝트 소개

DataManager는 DonkeyCar 자율주행 플랫폼을 보다 효율적으로 활용하기 위해 개발된 통합 관리 프로그램입니다.

---

## 👨‍💻 팀 구성

| 이름  | 담당 기능                                                                     |
| --- | ------------------------------------------------------------------------- |
| 문영진 | 데이터 관리 기능 개발 담당. 데이터 필터링(속도·각도), 프레임 범위 선택 및 삭제, 필터 목록 관리, 타임라인 시각화 기능 구현 |
| 배재용 | 모델 학습 기능 개발                                                               |
| 송찬휘 | 주행 분석 기능 개발                                                               |
| 김교범 | 차량 연결 및 데이터 동기화 기능 개발                                                     |

---

## ✨ 주요 특징

### ✔ 통합 환경 제공

* 데이터 관리
* AI 모델 학습
* 학습 결과 분석
* 차량 연결 및 동기화

### ✔ 직관적인 GUI

복잡한 터미널 명령어 대신 마우스 클릭만으로 대부분의 작업 수행 가능

### ✔ 시각적 데이터 분석

이미지, 그래프, 조향각, 속도 데이터를 실시간으로 확인 가능

### ✔ 데이터 정제 자동화

학습 품질을 떨어뜨리는 데이터를 빠르게 찾아 제거 가능

# 📂 1. 데이터 관리

## 개요

데이터 관리는 DonkeyCar의 주행 데이터(Tub)를 관리하고 정제하는 기능을 제공합니다.

### 📁 데이터 불러오기

* Tub 폴더 선택
* 이미지 자동 로딩
* 프레임 탐색

### 🎞 프레임 탐색

* 첫 프레임 이동
* 마지막 프레임 이동
* 이전/다음 프레임 이동
* 자동 재생

### 🎯 범위 선택 기능

* 좌측 설정
* 우측 설정
* 범위 목록 저장

### 🗑 범위 삭제 기능

* 선택 범위 삭제
* 전체 범위 삭제
* 삭제 데이터 복원

### ⚡ 속도 필터

* 특정 속도 범위 선택
* 필터 목록 관리

### 🔄 각도 필터

* 조향각 범위 필터링
* -1.0 ~ 1.0 지원

### 📈 타임라인 시각화

* 정상 데이터 표시
* 삭제 데이터 표시
* 선택 범위 표시
* 현재 프레임 표시
